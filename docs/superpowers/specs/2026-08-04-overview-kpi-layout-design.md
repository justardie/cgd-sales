# Overview KPI Layout Design

The Overview keeps its existing visual language and data. KPI cards use one shared height, render as one column on mobile, two columns on tablet portrait, and five columns from tablet landscape/desktop. All five cards share the same label, value, and supporting-text typography; decorative icons are removed, while the two percentage rings remain as data indicators. The active-sales label is shortened to `Sales Aktif` so it never truncates. The Omset per Proyek heading and project value cards remain; only the donut chart and its container are removed.

Success is verified by a source contract, lint, and production build.
